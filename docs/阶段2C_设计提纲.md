# 阶段 2C 设计提纲：可学习向量化 + 深度学习融合

> 依据：阶段 2B 核心洞察「稳定性 ≠ 判别力」——固定向量化（Top-K/PI/PL/Betti）各有短板，
> 没有单一最优 → 让网络自适应学习 PD → Banach 空间的映射（PersLay 思路）。

## 任务分解

### 2C-1 PersLay-lite 可微向量化层（`src/perslay_lite.py`）

固定向量化 = 手工选核函数与权重；PersLay-lite 把它们变成可学习参数：

- **点权重**：w_i = sigmoid(a·pers_i + b)，a、b 可学习——网络自己决定"多持久才算显著"
  （对应 2A 判据优化里手工调的 30% 比例阈值，现在让数据说话）
- **核函数**：全局可学习带宽 σ 的高斯核，PD 点 (birth, pers) 投影到 G×G 网格
  （对应 PI 的固定高斯核，现在 σ 可学习）
- **输出**：G×G 展平特征向量 → LayerNorm → MLP 分类头

**不可微边界**：ripser PH 计算不可微 → PD 预计算缓存（200 条 ECG 一次算完存 .npz），
可学习部分从 PD 之后开始。这是 PersLay 原论文的标准做法。

### 2C-2 ECG200 端到端分类

- 数据：ECG200（100 train / 100 test），Takens 嵌入 m=5, τ=4（2A 冲刺最优参数），H1 持续图
- 模型：PersLay-lite(G=20, 400D) → Linear(400→32) → ReLU → Dropout(0.3) → Linear(32→1)
- 协议：train 上 5 折 CV（早停、选 epoch），test 只评一次——与 2A/2B 完全一致
- 对比基线：固定向量化最优 Top-K+RF = 74%（2B 任务 3）

### 2C-3 拓扑 + 时频融合

- PersLay 特征 (400D) 拼接时频特征 (11D) → MLP
- 对比基线：固定特征融合 28D + RF(50) = **85%**（2A 冲刺，当前项目最佳）
- 成功标准：≥85% 追平/超过；或 CV 稳定性显著占优（两者都支撑创新点）

## 防过拟合设计（train 仅 100 条）

1. 小模型：hidden=32，参数量 ~13k
2. 正则：dropout 0.3 + weight decay 1e-3
3. 早停：CV 折内 val loss patience=30
4. 最终 epoch 数 = CV 各折最优 epoch 中位数（不看 test）
5. 全批量梯度下降（数据小），Adam lr=1e-3

## 产出

- `src/perslay_lite.py`（可复用模块）
- `src/experiment_2c_ecg200_perslay.py`（端到端实验）

  这是创新点最直观的证据
