## 第二章 相关工作与实验框架

2.1 五篇基线论文综述（DNA 结构 / 喷注标记 / TopoGAT / 3DPHDL / 自适应过滤）
2.2 统一实验框架：`ph_pipeline.py` 核心模块（PH 计算 + 四种向量化 + 评估指标）

## 第三章 三维形状的拓扑特征识别（阶段 1）

3.1 复形参数稳健性（子任务 A）
   - 绝对 WD 阈值判据（点云直径 ×10%）；5–15% 敏感性分析证明稳健
   - 结论：子采样率 ≥50% 时拓扑特征稳定
3.2 合成数据：拓扑 vs 几何（子任务 B）
   - SO(3) 随机旋转下：拓扑 91.1% vs 几何 71.4% vs PCA25 63.5%
   - 旋转不变性是本质优势（呼应申报书"打破欧式距离依赖"）
3.3 真实数据：ModelNet10（子任务 C）
   - 严格协议（10 类全量 + GroupKFold + 256 点）：拓扑 48.9% / 几何 70.1% / 融合 76.8%（RF 79.68%）
   - 讨论：真实 CAD 物体类间拓扑差异天然有限；**融合 +6.7pp 是拓扑补充价值的核心证据**
   - 诚实说明：未达 85% 的原因（类别数、防泄漏协议、采样密度、FPFH 库 bug 降级方案）

## 第四章 时间序列的拓扑表征（阶段 2A）

4.1 Takens 延迟嵌入：参数选取逻辑（自相关/互信息 τ、FNN m）
4.2 合成动力学验证：周期(1 环)/拟周期/混沌(73-127)/噪声(377-531)
   - 比例判据（持久度>30%最大值）在混沌vs噪声上区分度 9.12，绝对阈值失效
4.3 ECG200 实证：
   - 基线：拓扑 73% / 时频 78% / 融合 83%（+5pp）
   - 冲刺：拓扑特征 9D→17D（Betti+景观）+ 参数 CV（m=5,τ=4）+ RF(50) → **融合 85.0% 达标**
   - 发现：小数据集上 RF(50) > RF(200)，集成投票失效

## 第五章 向量化方法的系统比较（阶段 2B）

5.1 四种向量化：Top-K / PI / PL / Betti（统一固定范围归一化）
5.2 噪声稳定性：PI(0.085) > Betti(0.239) > Top-K(0.337) >> PL(0.652)
5.3 旋转连续性：持久图严格旋转不变（Ripser 距离矩阵性质）
5.4 分类判别力（ECG200）：Top-K(74%) > PI/PL(72%) > Betti(68%)
5.5 **核心发现：稳定性 ≠ 判别力**——平滑性抗噪但抹去判别细节；没有单一最优向量化

## 第六章 可学习向量化（阶段 2C）

6.1 PersLay-lite 设计：可学习权重 sigmoid(a·pers+b) + 可学习带宽 σ
   - σ 插值视角：σ→0 ≈ Betti 类点测度，σ→∞ ≈ PI 类全局平滑（理论观察）
6.2 ECG200（100 样本）：参数饥饿，test 落后 7pp；混合方案（表征+RF）81% 最佳
6.3 FordA（3601 样本，拓扑弱相关）：参数真学习（σ 0.10→0.048），差距缩至 −1.6pp；
   纯拓扑仅 50-62%——任务无拓扑信息可挖
6.4 ECG5000（500 样本，5 类心律，拓扑强相关）：
   - 纯拓扑 87.5-89.8%（结论 1 的直接证据）
   - PersLay混合+RF 92.0% vs 固定 91.4%（5/5 种子一致，配对 t p<0.0001，McNemar p=0.041）
   - **诚实修正**：类别不平衡 146×，macro-F1 口径固定基线占优（0.468 vs 0.439）；
     accuracy 口径表述为"追平/略优"
6.5 **核心结论：数据量 × 任务拓扑相关性双重门槛**
6.6 方法学附属发现："可学习表征 + RF"三数据集一律优于端到端 MLP

## 第七章 总结与展望

7.1 三个核心结论（见导师讨论材料）
7.2 85% 目标答卷：ECG200 达标 85.0%；ModelNet10 严格协议 76.8%（合理性论证）
7.3 局限性：
   - ModelNet10 几何基线受 open3d FPFH bug 影响（降级为 numpy 特征）
   - ECG5000 少数类（train 仅 2-10 样本）无法有效评估
   - PersLay-lite 是简化版（单 σ 全局核），未实现原论文的逐点可学习核
   - 嵌入参数在 FordA/ECG5000 上未单独扫描（沿用 ECG200 最优）
7.4 展望：
   - σ 插值理论深化（小命题 + 证明）
   - 端到端可微 PH（如可微 Rips 近似）
   - 更大规模时序/三维数据上的验证
